Control central para fuentes de navegador en OBS Studio

01. Intro 10s

Animación principal de bienvenida. El logo se dibuja con circuitos y presenta el evento. Termina en negro (fade-out).

02. En Breve Loop infinito

Pantalla de espera para colocar antes de comenzar el evento o entre bloques largos.

Abrir Overlay

03. Transición Speaker 8s

Anuncia "A continuación..." mostrando qué charla viene. Lee datos dinámicamente de speakers.json.

Abrir Overlay

05. Lower Third Toggle / Loop

Banda inferior con el nombre y cargo del speaker para sobreponer en la cámara. (Transparente).

Abrir Overlay

06. Intermedio Loop infinito

Pantalla de "Coffee Break / Regresamos en breve". Usa la paleta magenta para diferenciarla del inicio.

Abrir Overlay

07. Cierre Estático

Pantalla final de "Gracias por participar". Las partículas y circuitos se detienen en una imagen fija.

Abrir Overlay

Cámaras y Diapositivas (Transparencias PiP)

08. Layout Keynote PiP

Gran espacio para PPT y cámara circular flotante. Perfecto para ponencias principales. (Huecos transparentes para OBS).

Abrir Overlay

09. Layout Split PiP

Pantalla dividida (40% cámara izquierda, 60% PPT derecha) con separadores neón dorados.

Abrir Overlay

10. Layout Presenter PiP

Cámara principal de gran tamaño y presentación pequeña. Ideal para Q&A o discusión.

Abrir Overlay
